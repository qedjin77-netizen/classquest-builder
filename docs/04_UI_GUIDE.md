# UI/UX Guide

## 대상

- 교사: 코딩 지식 없이 20~30분 안에 게임 제작
- 학생: 초등학교 3~6학년, 수업 중 빠른 이해와 조작

## 기본 원칙

- 귀엽고 밝은 캐주얼 게임 분위기이되 특정 상용 게임의 UI를 복제하지 않는다.
- 핵심 행동은 한 화면에서 하나씩 명확히 보여준다.
- 버튼과 클릭 영역은 최소 44×44px를 유지한다.
- 학생 문구는 짧고 쉬운 한국어를 사용한다.
- 색상만으로 상태를 구분하지 않고 아이콘·텍스트를 함께 쓴다.
- 키보드 이동, 포커스, 명도 대비를 고려한다.

## 주요 흐름

### 교사

게임 목록 → 새 게임 → 기본 정보 → 방 편집 → 문제 편집 → 미리보기 → 게시 → 수업 시작 → 실시간 대시보드

### 학생

세션 코드 → 닉네임 → 대기실 → 방 1 → 방 2 → 방 3 → 탈출 결과

## 제작기 레이아웃

- 상단: 저장 상태, 미리보기, 게시
- 좌측: 배경·오브젝트·문제 자산
- 중앙: 방 캔버스
- 우측: 선택 오브젝트 속성·문제 연결
- 하단 또는 별도 패널: 레이어·Undo/Redo·방 이동
