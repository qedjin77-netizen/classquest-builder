# Game Rules

## 기본 구조

- 게임당 방 3개
- 방당 문제 3~5개
- 모든 문제 필수
- 방 안 문제 순서는 자유 탐색
- 방 사이는 1 → 2 → 3 순차 진행

## 오답과 힌트

- 재도전 무제한
- 같은 학생이 같은 문제를 2회 틀리면 3회차부터 힌트 확인 가능
- 문제당 힌트 1개

## 완료 조건

- 현재 방의 모든 문제가 해결되면 출구 개방
- 세 번째 방을 완료하면 탈출 성공
- 교사 확인 완료는 출구 조건에 반영할 수 있으나 실제 정답 통계와 분리

## 팀전

- 2~6팀
- 학생을 가능한 한 균등 배정
- 문제 해결 상태는 팀 공유
- 오답 횟수와 힌트는 학생 개인별

## 시간 제한

선택 기능이며 기본값은 제한 없음이다. 서버 시각을 기준으로 판정한다.
