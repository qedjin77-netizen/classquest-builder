# Architecture Decision Records

중요한 기술·도메인 결정을 ADR로 기록한다.

요구사항 전체 결정의 기준은 `docs/01_REQUIREMENTS_DECISIONS.md`이며, 이 폴더는 구현 구조에 큰 영향을 주는 결정을 빠르게 찾기 위한 색인이다.

## ADR 목록

- [ADR-001 — Supabase](ADR-001-SUPABASE.md)
- [ADR-002 — Team Mode](ADR-002-TEAM-MODE.md)
- [ADR-003 — Version Policy](ADR-003-VERSION-POLICY.md)
- [ADR-004 — Student Identity](ADR-004-STUDENT-IDENTITY.md)

## 상태 규칙

각 ADR은 다음 상태 중 하나를 명시한다.

- Proposed
- Accepted
- Superseded
- Rejected

결정을 변경할 때는 기존 ADR을 삭제하지 않고, 새 ADR에서 대체 관계를 기록한다.
