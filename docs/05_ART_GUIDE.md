# Art Guide

## 방향

한국 초등학교 3~6학년이 친근하게 느끼는 밝고 귀여운 2.5D/3D 카툰 스타일을 사용한다. 특정 상용 게임의 캐릭터·UI·배경을 복제하지 않는다.

## 시각 언어

- 둥근 실루엣과 부드러운 모서리
- 따뜻한 조명과 명확한 전경·중경·배경 구분
- 문제 오브젝트는 배경에서 충분히 식별 가능
- 지나치게 무섭거나 어두운 연출 금지
- 텍스트가 들어간 이미지 자산은 최소화

## 방 템플릿

- 기본 3개 방을 한 게임에서 순차 사용
- 배경과 오브젝트는 독립 자산으로 교체 가능
- 과학 등 단일 과목 테마로 모든 방을 구성할 수 있음
- 중앙 탐색 공간과 UI 안전 영역 확보

## 자산 규격

- 배경: 웹 최적화 이미지, 화면 비율과 안전 영역 명시
- 오브젝트: 투명 배경 PNG 또는 WebP
- 캐릭터: 동일 비율·조명·시점 유지
- 자산 ID·카테고리·태그·권리 정보를 마스터 데이터로 관리
