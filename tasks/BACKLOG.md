# Backlog

현재 Sprint에 포함하지 않는 승인 대기 또는 후순위 작업을 관리한다.

## 제품 기능

- [ ] 교사 인증과 권한
- [ ] 데이터베이스 스키마와 RLS
- [ ] 교사용 게임 제작 기본 흐름
- [ ] 자유 배치 편집기
- [ ] 학생 입장·대기실·플레이·탈출
- [ ] 실시간 교사 대시보드
- [ ] 기본 팀전
- [ ] 콘텐츠 공개·검색·미리보기·복제
- [ ] 대기실·방별·탈출 오디오

## 설계 문서

- [ ] DB 스키마 확정 후 `docs/03_DATABASE.md` 갱신
- [ ] 첫 UI 구현 전 `docs/04_UI_GUIDE.md` 상세 토큰 확정
- [ ] 실제 자산 제작 전 `docs/05_ART_GUIDE.md` 승인
- [ ] 배포 착수 전 `docs/08_DEPLOYMENT.md` 환경별 체크리스트 확정

## 범위 제외 항목

다음 항목은 현재 Backlog가 아니라 **명시적으로 제외된 범위**다. 사용자가 프로젝트 범위를 공식 변경하고 관련 기준 문서를 함께 수정하기 전에는 작업 항목으로 전환하지 않는다.

- 유료 콘텐츠 거래
- 교사 사용자 자산 업로드
- 고급 팀 역할·경쟁 기능
- AI 기능 전체
