## 운영 규칙

1. 새로운 Sprint를 시작할 때 `Sprint-NN.md`를 새로 만든다.
2. 진행 중에는 해당 Sprint 파일만 갱신한다.
3. 완료된 Sprint 파일은 원칙적으로 수정하지 않는다.
4. 과거 기록의 오기나 깨진 링크를 수정할 때는 수정 이유를 해당 파일에 남긴다.
5. 제품 사양 변경은 Change Log만 수정하지 않고 `PROJECT.md`와 관련 기준 문서를 먼저 갱신한다.
